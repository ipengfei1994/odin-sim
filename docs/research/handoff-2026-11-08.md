## 5. 边界与纪律（给所有对接方）

1. **不代填**：工程侧不替研究者写公式、定阈值、升格「建议」为「标准」，也不代签任何决策栏。
2. **引用规范**：一律以《实验指标体系 v2》§章节号 + 知识库条目名引用，**不写本机绝对路径**。
3. **证据分级**：A 原文 / B 权威二手 / C 问答笔记 / D 摘要级。**C 级不得作公式或阈值依据**——已发现一份 C 级笔记所记 Cheng 数据（49.0%/84.4%、κ=0.31/0.67/0.86、1200 条）与原文（85–86%、κ=0.70、每标签分层 100 条、全文无 ICC）不符。
4. **定位边界**：合成真值锚 ≠ 人机对齐，只验证「引擎状态 → 文本 → 投影」这条通道读得回；不能据此声称 algorithmic fidelity 或把结论外推到真实人群。接真实 LLM 后若文本与 `opinion_true` 脱钩，合成锚失效，须退回纯无锚的探索式定位。
5. **引用纪律**：外部方法学（Shrout–Fleiss 1979 / Koo–Li 2016、NetworkX 默认值、Newman 2003 等）**只作候选登记，0 条采纳**；工具库默认值 ≠ 项目规格。
6. **架构约束**：核心层零反向依赖，`api/` 不 import `ui/`；研究能力放在独立扩展包，以保住既有 G3 指纹回归。
