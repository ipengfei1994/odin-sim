## 0. 使用方式

1. 先答 §1 的 3 个全局确认项（决定整套规范是否成立）。
2. 按 §2 的 D1→D7 顺序逐行填写「决策记录」列；**27 项阻塞级必须有书面结论**，否则对应指标在 S4 阶段只能进入 `skipped_metrics`。**D1、D2、D3 已按证据分流为表 A / 表 B 两栏**，逐项原文与出处分别见 `s0-evidence-D1.md` / `s0-evidence-D2.md` / `s0-evidence-D3.md`，三份证据稿只提供证据、不代填结论。**D2 另有 `validity-layer-v2.md` 重构稿**：把 L1 重排为「段 0 定位 / 段 1 门槛 / 段 2 风险双轨 / 段 3 门控」并给 Q-08~Q-11 决策卡，含 3 处对 D2 原结论的更正；该稿同样只给候选、不代填结论，且**不改 75 个 `metric_id` 与 43 条 TBD**。
3. 每条结论按 §3 的最小格式书写，并带定义版本 tag。
4. 在 §6 签署评审结论与授权范围。
5. 未授权前，工程侧**不改动 `src/`**。

**「阻塞」的含义**（沿用主规范 §14.1）：不确认则该指标不能产出数值，不是"可以先算再改"。
