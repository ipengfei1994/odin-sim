# 新增拓扑的假设登记（ws / sbm）

- 日期：2026-10-28
- 状态：**待课题组确认**。以下参数与随机数消耗方式由本平台定义，用于让
  W2 的拓扑实验可以先跑起来；**不是**从参考文档或 baseline 推导出的既定口径。
- 涉及代码：`src/odin_sim/topology/generators.py`

---

## 为什么需要单独登记

baseline 只有 `ba` / `er` / `ring` 三种拓扑，参考文档 W2 要求四种（含 `ws`、
`sbm`）。新增拓扑意味着两件原本不存在的事：

1. **新的随机数消耗方式**——同一 seed 下得到哪张图，完全由"按什么顺序抽
   多少次随机数"决定。这是工程约定，但会影响任何跨拓扑对比的结论可复现性。
2. **新的结构参数**——WS 的重连概率、SBM 的块数与跨块稀疏比，都是**结构
   假设**，会直接影响动力学结果，因此属于研究口径而非纯工程默认值。

---

## A-1　Watts–Strogatz（ws）

| 项 | 取值 / 约定 | 说明 |
|---|---|---|
| 基底 | 规则环，每节点连左右各 `m` 个近邻（度 `2m`） | 与现有 `ring` 同一实现 |
| 重连概率 `beta` | **默认 0.10** | 标准 WS 小世界区间；未标定 |
| 遍历顺序 | `i` 升序，`k = 1..m` 升序，边记作 `(i, (i+k) % n)` | 决定随机数序列 |
| 判定抽数 | 每条边先抽一次 `rng.random()` | 不论是否重连都消耗一次 |
| 目标采样 | `rng.integers(0, n)` 拒绝采样，最多 20 次 | 禁止自环与重边 |
| 采样失败 | **放弃本次重连，保留原边** | 避免度序列被悄悄改变 |
| 度序列 | 重连只换端点不增删边，平均度守恒为 `2m` | 已由测试断言 |
| `beta = 0` | 应退化为 `ring` | 已由测试断言（hash 相同） |

## A-2　随机块模型（sbm）

| 项 | 取值 / 约定 | 说明 |
|---|---|---|
| 块数 `n_blocks` | **默认 4** | 未标定；等大小划分，余数分给前几个块 |
| 块划分依据 | **按 node id 连续划分**，与初始立场无关 | 见下方"为什么不用立场分块" |
| 跨块稀疏比 `ratio = p_out / p_in` | **默认 0.20** | 未标定 |
| `p_in` | **不是自由参数**，由目标平均度 `2m` 反解 | `p_in = 2m / ((size-1) + (n-size)*ratio)` |
| 随机数消耗 | 按 `(i, j)` 升序遍历全部节点对，每对抽一次 `rng.random()` | O(n²) 次抽取，n=500 约 12.5 万次 |

**为什么块不按立场划分**：baseline 已有独立机制 `homophily`（按概率把跨立场
边重连为同立场边）来建模回声室。如果 SBM 的块再按立场划分，两个机制会
叠在一起、无法归因。因此 SBM 定位为"与立场无关的社群结构"，立场相关的
隔离由 `homophily` 单独负责——需要叠加时显式同时开两者，并在实验配置里记录。

## A-3　同配重连（homophily）对新拓扑沿用同一算法

`ws` / `sbm` 也支持 `homophily` 参数，使用与 baseline 完全相同的
`_rewire_homophily` 算法（平台侧复刻实现）。一致性已验证：在 `ba` 上，
平台侧重连后的 `network_hash` 与 baseline 逐位相同（`homophily` 取 0.0 与
0.85 两种，多个 seed）。

## A-4　随机数分流

网络生成统一使用 `SeedSequence([seed, 1101])`，与 baseline 的网络分流一致。
因此**同一 seed 切换到新拓扑不会改变 ba / er / ring 的结果**，三种既有拓扑
的 `network_hash` 在移植前后保持不变（已由回归测试断言）。

## 需要确认的问题

| 编号 | 问题 | 影响 |
|---|---|---|
| A-Q1 | `ws` 的 `beta` 默认值取 0.10 是否合适？是否要扫描（如 0.01 / 0.1 / 0.3）？ | 小世界性强度，直接影响传播与极化速度 |
| A-Q2 | `sbm` 块数 4 与 `ratio` 0.20 是否合适？ | 社群强度；`ratio` 越小越接近"互不相通的回声室" |
| A-Q3 | 是否接受"SBM 与立场无关、homophily 单独建模"的拆分？ | 影响机制归因；若课题组希望 SBM 直接按立场分块，需改实现 |
| A-Q4 | 新拓扑是否需要与 `ba` 做**平均度匹配**后再比较？目前靠 `2m` 反解实现，但 `sbm` 是概率性的，实测平均度有波动 | 跨拓扑比较的公平性（当前测试容差 0.5） |
